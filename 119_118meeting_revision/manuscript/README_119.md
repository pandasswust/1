# 119 manuscript revision guide

## What changed

The revised `119.tex` now contains:

1. **Section 4.1 - Experimental design, dataset inventory, and upload
   manifest.** A 12-row experiment matrix (E0-E11), a six-row dataset card,
   explicit answers to "which experiments, which datasets, which uploads, and
   are the experiments sufficient", and an honest report of the severe
   depth-only statistical tie.
2. **Section 4.7 - Dataset atlas.** Figure 7: actual NYU RGB, metric depth,
   dense annotation masks, mask overlays, class colour codes, and Go1 nominal /
   degraded RGB with online-versus-truth terrain strips.
3. **Section 4.8 - Qualitative clustering and per-class error analysis.**
   Figure 8 and a 20-seed per-class recall table. This exposes the
   silhouette-versus-accuracy paradox and the class collapse hidden by
   aggregate ACC.
4. **Section 4.9 - Runtime, paired statistics, and label efficiency.**
   Figure 9, a CPU latency table, and a Wilcoxon table over 20 paired seeds.
5. **Data and Code Availability** before the acknowledgments.

## Compile

The source requires XeLaTeX because it uses `fontspec`:

```bash
xelatex 119.tex
xelatex 119.tex
```

The figure search path is `./`, `ge1031/`, `figs/ge1031/`, `figs/`,
`../figures/pdf/`, and `figures/pdf/`. The 13 figure PDFs are already copied
next to `119.tex` in this package, so it compiles directly. The
`\IfFileExists` fallbacks make the document compile even when a figure is
missing; a framed placeholder with the panel description is then shown.

## Canonical new values

- Runtime per frame: health 0.25 ms, softmax 0.014 ms, readout K=3 0.040 ms,
  readout K=32 0.045 ms, ExtraTrees inference 15.1 ms.
- Offline: RW-MVK K=3 calibration 27.8 ms, K=32 calibration 235.9 ms,
  ExtraTrees training 394.2 ms.
- Wilcoxon (20 seeds): clean depth-only gain +6.08 pp (p = 9.4e-5); severe
  depth-only gain +0.39 pp (p = 0.797, tied). All other severe baselines are
  significantly worse (p < 0.012).
- Label efficiency (Go1 blocked CV, mean +/- s.e.m.): 25% labels cluster
  77.7 +/- 3.8%; 100% labels cluster 77.9 +/- 3.3%; supervised 76.4 +/- 4.4%
  and 80.2 +/- 4.6%.

## Integrity note

The raw 2.97 GB NYU Depth V2 `.mat` archive is not redistributed. The extraction
script and the 51 selected RGB/depth/mask/overlay samples are included. All
other data are generated by the released scripts and ROS/Gazebo world files.
